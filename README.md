# 🏙️ Global Property Innovation

**Global Property Innovation** is a modern **real estate website** built with **Next.js**.  
It showcases premium properties, villas, and developments with an elegant UI, smooth animations, and responsive design.  
This project is designed to represent the identity and luxury style of the brand — using a gold and dark brown color palette.

---

## ✨ Features

- 🏠 **Property Listings** — Display available properties with images, descriptions, and details  
- 🔍 **Smooth Navigation & Scroll Animations** — Built using Framer Motion and React Scroll  
- 🖼️ **Slideshow & Gallery** — Beautiful property image slider powered by `react-slideshow-image`  
- 📩 **Contact Form Integration** — Connected with **Resend** for email handling  
- 🌙 **Responsive & Elegant Design** — Built with Tailwind CSS for seamless mobile and desktop layouts  
- ⚡ **Optimized Performance** — Uses Turbopack and Next.js 15 for lightning-fast builds
